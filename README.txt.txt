SISTEMA DE INVENTARIO

Cómo ejecutar:
Abrir el archivo index.html en un navegador web.

Funciones operativas:
- Registrar productos.
- Validar los datos ingresados.
- Mostrar los productos registrados.
- Buscar productos por nombre o ID.
- Mostrar todos los productos.
- Filtrar productos con stock bajo.
- Actualizar el stock de un producto.
- Mostrar un resumen del inventario.

Tecnologías utilizadas:
- HTML
- CSS
- JavaScript

Servicio/API:
No se utiliza ningún servicio o API externa en esta entrega.

Observación:
Esta versión corresponde a la Entrega 1 del proyecto. El sistema funciona de manera local y utiliza JavaScript para el manejo de los datos, validaciones, búsqueda, filtrado y actualización del inventario.
